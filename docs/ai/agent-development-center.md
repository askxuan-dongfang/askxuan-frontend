# 问事智能体开发中心

左侧原「AI 问事」与单独的「模型连接设置」统一到「问事智能体开发中心」。仅平台超级管理员可进入。面向用户仍是一位问事助手；专题是其业务能力，不是新建的独立智能体。

| 工作区 | 地址 | 用途 |
| --- | --- | --- |
| 智能体编排 | `/admin/ai/agent` | 职责、默认模型、知识与记忆权限、联网权限、Harness 检索策略 |
| 模型与连接 | `/admin/ai/connections/models` | 大模型、视觉模型与上下文参数 |
| ↳ 联网搜索 | `/admin/ai/connections/search` | 搜索引擎、独立主备密钥、连接测试与搜索预算 |
| ↳ 知识模型 | `/admin/ai/connections/knowledge` | Embedding、Rerank、KnowledgeQA 的接入与测试 |
| 知识中心 | `/admin/ai/knowledge` | WeKnora 文档、解析、审核、检索、Wiki 与实体图谱 |
| 技能与工具 | `/admin/ai/tools` | 已接入能力的添加、移除和启停 |
| 调试工作台 | `/admin/ai/debug` | 已保存草稿的 Harness 调试、补问和结果检查 |
| 质量评测 | `/admin/ai/evaluations` | 用例维护、评测运行与失败检查 |
| 版本与发布 | `/admin/ai/releases` | 发布、灰度与回滚 |
| 运行监控 | `/admin/ai/runs` | 生产执行、调试记录、工具轨迹及用量 |

推荐流程：配置连接 → 整理知识 → 编排助手与工具 → 保存草稿 → 调试与评测 → 发布 → 查看运行记录。

智能体编排、技能、调试、评测、版本与运行模块共享当前草稿，内部导航保留未保存修改。离开这些模块前若有未保存修改，需确认丢弃。大模型与联网搜索共享服务配置草稿，两页切换保留输入，保存时一并提交；离开连接配置时提示未保存修改。服务连接保存立即影响新请求，智能体草稿须评测并发布后生效，两者不混用发布按钮。

旧 `/admin/ai/operations` 和 `/admin/settings/ai` 链接分别跳转到编排与大模型连接，保留查询参数和锚点。直接链接、刷新、浏览器返回对应当前工作区。

此次调整是现有功能的信息架构与路由整合，不更换后端 Harness、API、权限、密钥存储、知识数据或现有发布版本；不新增任意第三方 MCP 安装或多智能体功能。
