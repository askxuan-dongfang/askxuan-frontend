# 问玄东方品牌标识

日出、山川与圆融的印记构成共同骨架。六枚标识分别用于信众（母品牌）、法师、寺院、商城、平台与东方珠作；普通功能图标、用户头像和太卜独立品牌不在此体系内。

- 浅色：松绿 `#244C43`、古金 `#987342`，适配米白界面。
- 深色：暖金 `#E5CCA3`、陶朱 `#D98B70`，适配深棕界面。
- 应用图标：信众松绿、法师朱砂 `#A94132`；另有深棕系统外观版本。
- 页面使用 `logo-*-light/dark.svg`（96 单位矢量）或透明 PNG（512 px），保持纵横比，不裁圆、不加底色壳、不拉伸。深浅版跟随应用实际主题。
- 应用图标使用完整方形、不透明 1024 px PNG，由操作系统裁出图标轮廓；图形处于 maskable 安全区域内。
- 浏览器图标另行移除应用图标的安全留白，提高 16–32 px 的辨识度。

`generate.mjs` 是正式图形的可编辑矢量源，`assets/` 为发布资产，`index.html` 为可切换浅深色的对照预览。生成器须 Node.js 与 sharp 0.35.4：在此目录安装依赖后运行 `npm run generate`；也可通过 `BRAND_SHARP_MODULE` 指定已安装的 sharp 模块目录。Web/iOS 构建直接使用已提交资产，不依赖生成器。

概念阶段使用内置 imagegen 探索“东方日出、月门、山川路径与六种身份”方向。正式 SVG 为人工编写的几何图形；PNG 是这些 SVG 的确定性栅格导出，不是概念图截取或旧位图改色。中文品牌名称继续使用产品已有衬线字体，图形中不嵌入小字。
