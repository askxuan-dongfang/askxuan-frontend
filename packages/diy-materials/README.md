# DIY 材质资源

`DiyMaterials/` 是 iOS 与 H5 共同使用的材质目录。iOS 将整个目录打包为资源；H5 镜像位于 `apps/web-h5/public/assets/diy/materials-v2/`，渲染配置镜像位于 `src/features/diy/material-profiles.json`。

更新源文件后，在 H5 仓库运行：

```sh
node scripts/sync-diy-materials.mjs
npm run check:diy-assets
```

校验包括原始素材 SHA-256、两端资源清单和字节一致性。H5 发布流程固定 frontend revision，防止跨仓库漂移。

## 内容与边界

- 8 张矿石、种子实拍参考，1 组实物木皮 PBR 扫描，以及摄影棚 HDRI。作者、授权、原始链接及哈希见 `sources.json`；对外署名见 `credits.html`。
- `appearance.json` 定义 20 类表面参数与当前 45 款材料映射，未知材料按纹理和材质类型回退。v3 区分木料哑光、玉石柔和高光与拉丝金属；已有材料的透光配置覆盖类别默认值。新增 SKU 不应直接借用其他 SKU 的照片。
- 运行时裁切、镜像、按材料配置调色；缩略图与 3D 使用同一纹理。照片参考不是在售商品实拍，也不是木种或宝石鉴定证据。星月菩提、金属、陶瓷、织物等仍使用程序表面；雕刻配件仅作外形示意。
- H5 使用物理透射和环境反射；SceneKit 通过双层透明表面与视角相关密度近似透光，不具备等同的体积折射。光学参数用于视觉预览，未经过实物测量。
- 珠体含贯穿孔，材质按粗糙度、涂层、金属度和透射区分。生产自定义素材优先于内置参考，旧演示木材贴图由新资源替换。

## 配件几何 v1

`generate-geometry.mjs` 生成本项目原创的网格、目录与灰度缩略图。`geometry-*.json` 为三通、母珠佛头、莲花 / 葫芦 / 平安扣 / 木鱼吊坠、流苏和中国结流苏的共享网格；H5 与 SceneKit 读取相同顶点、法线、UV 与索引。PNG 缩略图由同一网格离线投影，运行时覆盖当前材料纹理，卡片与预览因此使用同一轮廓。

- 坐标按名义直径归一化，X 为穿绳轴，Y 向上，Z 指向手串外侧。三通与佛头母珠的左右贯穿孔与外侧出口真实连通；佛头不绘制人物头像。
- 标准圆珠、桶珠、切面珠与隔片保留旋转体参数模型。`12×30mm` 桶珠按 30mm 轴长排布；缺失轴长时采用形状默认比例。
- 资源原点为原穿孔中心，`anchors.mount` 标明装饰主体上端的悬挂连接点，局部 +Z 沿装饰主体延伸。平放时朝环外；悬挂时环转为 XY 平面，挂件 +Z 恒朝世界 -Y，使用独立连接绳与有界阻尼刚体摆动。相机旋转不改变重力；此实现不是布料或软体仿真。
- 吊坠、流苏手围只计挂环占宽，装饰主体宽度单独参与避碰间距；切换展示不改变手围、顺序或商品数据。内围为估算值，不是成品实测结果。
- 普通珠默认平放，包含吊坠或流苏时默认悬挂，并允许手动切换。进入悬挂时将挂件组朝下，后续编辑保持这一展示角度；平放恢复原布局。平放时各珠中心高度依据底面计算，绳线按穿孔轴连接；悬挂使用实际模型宽度和轻摆包络，仅在近邻接触时增加少量前移，连接绳向下量至少等于前移量。此为常见一至两个挂件的约束刚体展示，复杂多挂件及软体接触需专门仿真。
- 网格由程序建模，并非 SKU 扫描；木鱼、莲花和雕刻纹样只表达配件类别与安装关系，不能作为商品纹样、孔径或工艺确认依据。实物校准仍需要供应方的尺寸和素材。

运行 `node packages/diy-materials/generate-geometry.mjs` 重新生成；脚本同时更新 `sources.json` 中 `askxuan-accessory-models-v1` 的 SHA-256，随后再同步到 H5。定向测试通过真实网格射线验证相通孔路，并校验挂件占宽、混合珠径接触高度和资源字节一致性。模型缓存按种类共享；材料和场景继续按需渲染，低端真机性能单独验收。

运行时生成的裁切与调色纹理沿用原图许可；发布时保留署名、原图链接及修改说明。不要用来源不明的商城照片替换这些资源。
