# 问事智能体工作台

入口：平台总管理台 → AI 问事 → 智能体工作台。普通用户、师傅、寺观账户不可进入管理接口。

## 知识与能力

1. **模型与连接**登记 Embedding、Rerank、KnowledgeQA 并测试连接。预置模型只读，外部 HTTPS 域名需部署许可。换供应商请新建模型，密钥不会从查询接口返回。
2. **知识库**选择 Embedding 建库；上传文档或添加文本；等待解析、预览分块、填写出处后审核启用。Embedding 更换要新建库重索引。
3. **Wiki 与关系图**启用生成模型，查看队列、条目与出处；点击条目编辑或查看历史、恢复旧内容。质量检查可重建链接、修复结构问题、处理内容问题。生成与结构健康度不代表事实准确。
4. **实体图谱**选择文档理解模型、打开实体抽取并保存。已有资料要重新解析并审核；关系图支持拖动、搜索、实体列表、出处与分块。此图来自 Neo4j 文档实体；Wiki 图仅表示条目引用关系。
5. **技能与工具**管理已经接入的技能/MCP，不安装任意第三方服务。

## 智能体开发

本系统面向用户提供一个问事智能体。配置职责、默认模型、预算、技能工具权限、知识库与记忆开关；检索策略可设置候选数、引用数、重排模型、失败回退和实体扩展。保存草稿后进入调试与发布。配置的改变不会直接影响用户会话。

## 调试与发布

使用代表问题调试，检查工具输入输出、检索出处与降级状态；运行质量评测；符合发布门禁后发布版本，配置灰度覆盖；运行记录核对实际生效版本和调用轨迹。异常时回滚版本。Embedding 绑定影响知识库索引，Rerank 策略随智能体版本冻结。

当前预置：512 维 BGE small zh 向量、BGE reranker base 中文/英文 CPU 重排、DeepSeek 文档理解与 Wiki。未审核、停用、重解析中的资料不会供用户检索；存量图谱不能绕过审核撤销。
